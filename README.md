# Listenook / 聆页 Releases

Download published installers from the [Releases](../../releases) page.
Historical MeowSTT releases remain available.

## Moving from MeowSTT

The first Listenook installation is manual. Quit MeowSTT, including its menu-bar
or tray process, before opening Listenook. First launch migrates the local
library, settings, completed models, downloaded podcasts and API keys, and keeps
the old data for recovery. Later Listenook versions use the normal updater.

## Update feeds

- `latest.json` remains the legacy MeowSTT update manifest. It is not advanced
  to Listenook packages.
- Listenook uses `listenook-latest.json`, published with the first Listenook
  release. The release publisher updates this feed after uploading its assets.

Keep historical tags and assets intact so existing download links continue to work.
